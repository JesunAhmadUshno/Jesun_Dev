What this policy covers

This policy covers three things, all run by me personally, for my own automation work:

  • This website, jesunahmadushno.com.
  • The "Jesun n8n Automation" app on Meta for Developers.
  • The "Jesun n8n" project on Google Cloud.

The automation runs on an n8n instance on my own self-hosted server. There is no company behind it and no outside operator. If you have a question about this policy, email me at jesunahmadushno@gmail.com.

Google data

With my own Google sign-in and my own OAuth consent, the automation can reach five of my own Google services:

  • Gmail
  • Google Calendar
  • Google Drive
  • Google Sheets
  • YouTube (read access)

This is my own account data, not yours. The automation uses it only to run my own workflows on my own server, for example sorting my own mail or reading my own calendar. No other person's Google account is connected, and the automation never asks visitors of this site to sign in with Google.

Plain statement on Google data: the data is my own Gmail, Google Calendar, Google Drive, Google Sheets, and YouTube data, from my own Google account, reached with my own OAuth consent. It is processed by n8n on my own self-hosted server, and only to run my own automations. It is not sold to anyone. My own Google account data in this automation is not used for advertising. Website advertising is covered in the Advertising section below. It is not handed to any third party: the only data transfers are the service calls to Google, Meta, and Cloudflare that run the automation itself. No human reads it except me: the editor and the stored credentials sit behind a login wall that admits only my email.

Meta data (Facebook and Instagram)

The Meta app is set up to connect to my own Facebook Pages and my own Instagram account. When you comment on one of my posts, or send me a message, the app can receive the comment or message so the request can be answered.

The main use is the keyword funnel. If you comment the keyword on a launch post, the tutorial or resource pack you asked for is sent to you by DM. Where the automatic connection is live, the automation sends it; where it is not yet switched on, I send it by hand. To do that, only what is needed gets used: your comment, your public name or handle on that platform, and the message thread with you. It does not pull your profile history, your friends list, or your activity on other pages.

If you never comment or message, the automation receives nothing about you from Meta.

Where data lives

Data stays in two places: on my own self-hosted server, and inside my own Google and Meta accounts. I do not sell data. I do not rent data. I do not sell data to analytics brokers. Website ads are served by Google, as described in the Advertising section below. The automation editor itself sits behind a login wall (Cloudflare Access) that lets one email in: mine.

Retention and deletion

Records tied to the keyword funnel, such as a DM thread or a fulfilment log entry, are kept for 12 months from the date of the request, so the request can be completed and checked later, and then they are deleted. You can ask for your data to be deleted at any time, sooner than that. Email jesunahmadushno@gmail.com and name the platform and the account you used. I will delete the records I hold for you and confirm by reply. Requests are honoured.

Cookies

This website is a static site. It is served by GitHub Pages, from the repository this site is built from, and delivered through Cloudflare. From outside the site, the page loads one resource: a stylesheet from Google Fonts, with the font files that come with it. Apart from the Google AdSense script described in the Advertising section, I put no scripts of my own in the page. Cloudflare adds one small script of its own as it serves the page, an email-decode script loaded from this site's own address, which turns the protected contact email address back into readable text. There is no analytics code on the page. If you visit a page with ads, Google AdSense may set advertising cookies, as described in the Advertising section. Otherwise the page sets no cookies from me. The n8n automation editor is not a public page; it is behind the login wall described above.
