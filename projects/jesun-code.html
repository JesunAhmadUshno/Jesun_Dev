Jesun.Code v1.0 soon

A programming language that reads like plain English. If a sentence makes sense to a person, it should make sense to the machine. No semicolons, no braces, plain-English errors with line numbers, the whole Python ecosystem via import, a package manager (jpm), AI agent fleets, and tmux control. Ships as a single binary; v0.6.0 runs 220/220 tests green. Self-hosting is the v1.0 milestone.
